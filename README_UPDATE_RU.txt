КНОПКА UPDATE — ЧЕРНИЛЬНАЯ АРЕНА

В главном меню desktop-сборки добавлена кнопка UPDATE.

Как пользоваться:
1. Соберите и установите игру через BUILD_FOR_SHARING.bat.
2. Откройте установленную desktop-игру и нажмите UPDATE.
3. Выберите ZIP проекта, которому доверяете.
4. Игра распакует архив во временную папку, прочитает package.json и покажет найденную версию.
5. Если в архиве уже есть InkArenaRemastered-Setup*.exe, игра предложит запустить его.
6. Если в архиве есть BUILD_FOR_SHARING.bat и package.json, игра предложит собрать установщик. Для этого на компьютере должны быть Node.js LTS и доступ к интернету для npm install.
7. Когда Setup будет готов, можно запустить установку поверх текущей версии.

Важно:
- Выбирайте только свои ZIP-архивы и доверенные сборки: сценарий сборки BAT выполняет команды на компьютере.
- В архиве проекта должен быть корректный package.json с номером версии.
- Установщик должен иметь тот же appId, чтобы NSIS мог обновить существующую установку.
- Реальную сборку Windows и сценарий обновления нужно проверить на Windows. В этой среде проверен синтаксис JavaScript Electron, но не была выполнена полная сборка .exe.
- Для автоматических обновлений из интернета отдельно настройте настоящий GitHub Releases owner/repo в package.json; пока кнопка UPDATE рассчитана на ZIP, который пользователь выбирает вручную.
