# Ink Arena Remastered — запуск в один клик (Windows)

1. Распакуйте весь ZIP в обычную папку.
2. Дважды щёлкните `START_GAME.bat`.
3. Если Node.js отсутствует, откроется официальный сайт https://nodejs.org/ — установите версию LTS и запустите `START_GAME.bat` ещё раз.
4. При первом запуске скрипт установит зависимости автоматически; нужен интернет.
5. Браузер откроется на `http://localhost:5173/`. Не закрывайте чёрное окно, пока играете.

Это не установочный EXE: в текущей среде не удалось выполнить сборку приложения в автономный Windows-бинарник. Этот запускатор убирает необходимость вручную вводить команды, но для запуска исходного React/Vite-проекта нужен Node.js.
