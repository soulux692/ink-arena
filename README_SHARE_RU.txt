INK ARENA REMASTERED — ГОТОВЫЙ УСТАНОВЩИК ДЛЯ ДРУЗЕЙ

Цель: собрать один Windows Setup EXE, в который встроены сама игра и Electron runtime.
На компьютере друга не нужен Node.js, npm или командная строка.

ВАЖНО: Этот ZIP всё ещё является ИСХОДНЫМ ПРОЕКТОМ для сборки, а не готовым Setup EXE.
Я не могу скомпилировать и проверить Windows EXE в этой среде.

СБОРКА (только на ПК создателя):
1. Установи Node.js LTS на своём компьютере.
2. Распакуй весь архив.
3. Запусти BUILD_FOR_SHARING.bat и дождись окончания.
4. Готовый файл появится в release\InkArenaRemastered-Setup-1.0.0.exe.
5. Друзьям отправляй только этот Setup EXE. Им Node.js не нужен.

Установщик должен позволять выбрать папку установки и создать ярлык на рабочем столе.
Если Windows SmartScreen предупреждает о неизвестном издателе, это может случаться с неподписанными самодельными установщиками.


ВАЖНО: ЭФФЕКТ РАЗРЫВА ЭКРАНА И ОБНОВЛЕНИЯ
- Реальный рабочий стол открывается только в desktop-сборке Electron. В браузере игра сохраняет старую визуальную имитацию.
- При pageCut окно Electron становится примерно вдвое уже, а сцена сохраняет исходную ширину; после снятия pageCut окно восстанавливает исходный размер.
- Автообновления подготовлены через electron-updater, но перед публикацией нужно указать настоящий GitHub Releases репозиторий в package.json -> build.publish:
  owner: имя владельца GitHub
  repo: имя репозитория
  Плейсхолдеры YOUR_GITHUB_USERNAME и YOUR_REPOSITORY нужно заменить на реальные значения.
- Чтобы обновления доходили друзьям, каждую новую сборку нужно публиковать в GitHub Releases вместе с файлами обновления, созданными electron-builder. Без настроенного публичного репозитория обновления не смогут скачиваться.
- В этой среде не удалось проверить Windows EXE: зависимости Vite в имеющемся node_modules неполные, поэтому сборку нужно проверить на Windows после npm install.
