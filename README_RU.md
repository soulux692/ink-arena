# Чернильная арена — обновлённая версия

Рисованный монохромный аренный шутер на React + TypeScript + Vite.

## Что изменено
- Обновлены подсказки управления: показаны быстрый выбор оружия `1–5` и переключение `Q`.
- В главном меню кооператив обозначен как онлайн/P2P, а не как функция «в разработке».
- Уточнён экран совместной игры: как пригласить друга и что доступно в кооперативе.
- Сохранены исходная рисованная графика, уровни, боссы, прогресс и сетевой код проекта.

## Запуск
Требуется Node.js 20 или новее.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`.
4. Запустите `npm run dev`.
5. Откройте адрес Vite, указанный в терминале.

## Сборка
`npm run build`

## Управление
- `WASD` — движение
- Мышь — прицел
- `ЛКМ` — стрельба
- `Q` или `1–5` — смена оружия
- `Space` — рывок
- `E` — ульта
- `Esc` / `P` — пауза

## Кооператив
Откройте «Совместно», создайте комнату и передайте другу ссылку или код. Для подключения через интернет обоим игрокам нужен доступ к сетевым сервисам, используемым PeerJS/WebRTC; доступность зависит от браузера и сети.
